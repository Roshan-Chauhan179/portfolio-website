# Roshan Chauhan | Personal Portfolio Website

A fully responsive personal portfolio website built with **HTML, CSS and JavaScript**.

**Live website:** https://roshan-chauhan179.github.io/portfolio-website/

## About

I'm Roshan Chauhan, a B.Tech CSE (Data Science & AI) student at Shri Ramswaroop Memorial University, Lucknow. This portfolio showcases my skills, education and projects.

## Sections

- **Home** – introduction with portrait
- **About Me** – who I am and what I bring
- **Services** – what I can build
- **Skills** – web technologies, languages, tools and databases
- **Education & Achievements** – timeline with downloadable resume
- **Projects** – filterable project showcase linked to GitHub
- **Contact** – validated contact form and social links

## Features

- Responsive layout for mobile, tablet and desktop
- Mobile navigation menu
- Project filter tabs (All / Python / Full Stack / PowerPoint)
- Contact form with JavaScript validation
- Scroll animations, 3D tilt effects and back-to-top button
- Downloadable resume (PDF)

## Technologies Used

- HTML5
- CSS3 (custom styles + Tailwind CSS via CDN)
- JavaScript (vanilla)

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
